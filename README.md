# منبّه الوالدة

تطبيق أندرويد واحد بيشتغل بطريقتين:
- **تليفون الوالدة**: الأدوية، الأذان وسؤال «صلّيتي؟»، منبّه قيام الليل، أذكار الصباح والمسا، تذكير الصيام، تسبيح بالصوت، وسجل آخر ٣٠ يوم.
- **تليفون المتابع (الابن)**: يشوف هي خدت الدوا وصلّت ولا لأ، ويجيله تنبيه لو حاجة فاتت أو لو تليفونها ما ظهرش من أكتر من ٦ ساعات.

التطبيق بيشتغل كامل على تليفون الوالدة لوحده حتى من غير الخطوة (أ). الخطوة (أ) لازمة بس عشان الربط بتليفون الابن.

---

## (أ) تفعيل الربط (Firebase) — مرة واحدة بس

1. افتح https://console.firebase.google.com وادخل بحساب جوجل بتاعك.
2. دوس **Create a project** (أو Add project)، اكتب اسم زي `mom-app`، وكمّل بـ Continue لحد ما يخلص (تقدر تقفل Google Analytics).
3. من الصفحة الرئيسية للمشروع دوس على علامة **أندرويد** (Add app ← Android):
   - في **Android package name** اكتب بالظبط: `com.zord.mom_app`
   - دوس **Register app**. لو طلب تنزّل ملف `google-services.json` **مش محتاجينه** — دوس Next لحد الآخر.
4. افتح ⚙️ **Project settings** ← تبويب **General**. هتلاقي:
   - **Project ID** ← ده `projectId`
   - **Web API Key** ← ده `apiKey`
   - تحت «Your apps» في تطبيق الأندرويد: **App ID** (بيبدأ بـ `1:`) ← ده `appId`
   - رقم **Project number** ← ده `messagingSenderId` (نفس الرقم اللي في نص الـ App ID)
5. افتح الملف `lib/firebase_config.dart` في GitHub (دوس على القلم ✏️ عشان تعدّله) وحط كل قيمة بين علامتي التنصيص:
   ```dart
   static const apiKey = 'AIza....';
   static const appId = '1:1234567890:android:abcdef...';
   static const messagingSenderId = '1234567890';
   static const projectId = 'mom-app-xxxxx';
   ```
6. فعّل الدخول المجهول: من القايمة **Build ← Authentication ← Get started ← Sign-in method ← Anonymous** ← فعّله ← Save.
7. اعمل قاعدة البيانات: **Build ← Firestore Database ← Create database** ← اختار مكان قريب (مثلاً `europe-west`) ← ابدأ بـ **production mode**.
8. انشر قواعد الحماية: في Firestore افتح تبويب **Rules**، امسح اللي مكتوب، والصق محتوى ملف `firestore.rules` اللي في المشروع، ودوس **Publish**.

> ملحوظة عن الأمان: الحماية هنا بسيطة — أي حد معاه التطبيق **ومعاه كود الربط (٦ أرقام)** يقدر يشوف البيانات. ماتديش الكود لحد غيرك.

كل ده مجاني (الخطة المجانية Spark كفاية جداً).

---

## (ب) الأصوات (أذان، منبّه، دوا، تسبيح)

**من التليفون نفسه (الأسهل):** نزّل ملف الصوت على التليفون (أو ابعته على واتساب واحفظه) ← **الإعدادات ← الأصوات** ← **➕ إضافة صوت من التليفون** ← اختار الملف. هيظهر في القايمة وتقدر تسمعه بزرار «تجربة» وتختاره، والأصوات اللي ضفتها تقدر تمسحها بعلامة الزبالة.
- التسبيح: **الإعدادات ← التسبيح بالصوت ← صوت التسبيح** ← اختار «صوت التليفون (قراءة آلية)» أو «تسجيلات صوتية» وضيف تسجيل أو أكتر (بيشتغلوا واحد ورا التاني).

**جوه التطبيق نفسه (يتسطّب جاهز من غير أي إعداد):** ارفع ملف `mp3` في GitHub في الفولدر المناسب (**Add file ← Upload files**):
- `assets/sounds/adhan/` أذان — `assets/sounds/alarm/` منبّه القيام — `assets/sounds/med/` الدوا — `assets/sounds/tasbeeh/` تسجيلات التسبيح
- اسم الملف **بالإنجليزي ومن غير مسافات**. لو الاسم بيبدأ بـ `main_` (مثلاً `main_haram.mp3`) يبقى هو الصوت الأساسي للقسم ده.
- لو في أي ملف في `tasbeeh/` التسبيح هيشغّل التسجيلات بدل القراءة الآلية.
- الأصوات اللي جاية مع التطبيق (`default_...wav`) أصوات هادية احتياطية — سيبها موجودة.

## (ج) رفع المشروع على GitHub وتنزيل التطبيق

1. اعمل حساب على https://github.com لو ماعندكش.
2. دوس **New repository**، سمّيه `mom_app`، واختار **Private**، ودوس Create.
3. دوس **uploading an existing file** واسحب **كل** ملفات وفولدرات المشروع (ومن ضمنهم الفولدر `.github`) ودوس **Commit changes**.
   - لو الفولدر `.github` ما اترفعش بالسحب، اعمله بإيدك: Add file ← Create new file واكتب في الاسم `.github/workflows/build.yml` والصق محتوى الملف.
4. GitHub هيبني التطبيق لوحده (حوالي ١٠ دقايق). تقدر تتابع من تبويب **Actions** (علامة ✅ خضرا يعني خلص).
5. التنزيل من الموبايل: افتح صفحة المشروع على GitHub ← **Releases** (على اليمين أو تحت) ← آخر نسخة ← دوس على **mom_app.apk**.
6. أي تعديل بتعمله (صوت جديد، إعدادات Firebase...) بيعمل نسخة جديدة لوحده. نزّلها وسطّبها فوق القديمة — **البيانات مش هتتمسح**.

> التطبيق متوقّع بمفتاح ثابت موجود في `android_overrides/debug.keystore` عشان كل نسخة جديدة تتسطّب فوق القديمة. خلّي المشروع **Private**.

## (د) التسطيب على تليفون الوالدة (OPPO)

1. افتح ملف `mom_app.apk` اللي نزلته. لو ظهر «تثبيت تطبيقات من مصادر غير معروفة» ← دوس الإعدادات ← اسمح للمتصفح/مدير الملفات ← ارجع وسطّب.
   لو Google Play Protect سأل، اختار **تثبيت على أي حال**.
2. افتح التطبيق واختار **تليفون الوالدة**.
3. هتظهر شاشة «عشان التنبيهات ما تتأخرش» — اعمل كل الخطوات بالترتيب ودوس الزراير:
   1. **اسمح بالإشعارات**.
   2. **المنبّهات في ميعادها** ← فعّل السماح.
   3. **البطارية** ← اختار «سماح» / «بدون قيود».
   4. **فوق شاشة القفل** ← فعّل.
   5. **التشغيل التلقائي** ← فعّل التطبيق. لو الزرار فتح صفحة معلومات التطبيق بدل كده، ادخل منها على **استخدام البطارية** وفعّل «السماح بالتشغيل التلقائي» و«السماح بالنشاط في الخلفية».
   6. **اقفل التطبيق في البرامج المفتوحة**: افتح قايمة البرامج المفتوحة، اسحب كارت التطبيق لتحت (أو النقط التلاتة ← قفل) لحد ما يظهر قفل صغير.
4. افتح تبويب **الأدوية** وضيف الأدوية ومواعيدها.
5. من **الإعدادات** اختار صوت الأذان وصوت المنبّه (أو ضيف أذان من التليفون، شوف (ب))، وشغّل/اقفل اللي هي محتاجاه (القيام، التسبيح، ...).
6. التسبيح بالقراءة الآلية محتاج صوت عربي في التليفون: الإعدادات ← إدارة إضافية ← اللغة والإدخال ← تحويل النص إلى كلام ← اختار محرك جوجل ونزّل اللغة العربية. لو مش موجود، التسبيح هيظهر كإشعار مكتوب.

الشاشة دي موجودة دايماً في **الإعدادات ← خطوات إعداد أوبو** لو احتجت ترجعلها (مثلاً بعد تحديث للتليفون).

## (هـ) ربط تليفون الابن (Samsung)

1. لازم تكون عملت الخطوة (أ) وسطّبت النسخة اللي فيها إعدادات Firebase على **التليفونين**.
2. على تليفون الوالدة: **الإعدادات ← ربط تليفون الابن** ← هتلاقي **كود من ٦ أرقام**. (التليفون لازم يكون عليه نت أول مرة.)
3. على تليفونك: سطّب نفس الـ APK ← اختار **تليفون المتابع (الابن)** ← اكتب الكود ← **اربط**.
4. هتشوف شاشة «النهارده» فيها كل دوا وكل صلاة وعلامة جنبها:
   - ✅ تمّ  — 🕒 متأخر — ❌ فات — ⏳ لسه
   وفوق «آخر ظهور» لتليفونها.
5. تليفونك بيراجع كل ربع ساعة تقريباً، ولو في دوا أو صلاة فاتت أو تليفونها ما ظهرش من ٦ ساعات هيجيلك إشعار.
   من القايمة (النقط التلاتة) ← **إعدادات البطارية** عشان سامسونج ما يقفلش التطبيق.

## إزاي التطبيق بيشتغل (باختصار)

- **مواعيد الصلاة** للإسكندرية بتتنزل من الإنترنت (الهيئة المصرية العامة للمساحة) لشهرين قدام وبتتحفظ على التليفون. لو مفيش نت والمواعيد مش محفوظة، التطبيق بيحسبها لوحده.
- **الدوا**: منبّه بصوت + إشعار فيه «أخدته» و«أجّل ربع ساعة». لو ما ردتش، بيرنّ تاني كل ١٠ دقايق ٣ مرات، وبعدها يتسجّل «فات».
- **الصلاة**: الأذان في ميعاده، وبعد ٢٠ دقيقة «صلّيتي؟». لو «لسه» أو ما ردتش، بيسأل تاني كل ٢٠ دقيقة لحد ربع ساعة قبل الصلاة اللي بعدها (الفجر لحد قبل الشروق، والعشا لحد نص الليل).
- **القيام**: منبّه صوته بيعلى بالتدريج ويفضل يرن لحد ما توقفه، وبعدها يسألها «قمتي؟».
- التطبيق بيجهّز مواعيد يومين قدام، وبيجدّدها لوحده كل ساعتين وكل ما يتفتح وبعد ما التليفون يتقفل ويفتح.
